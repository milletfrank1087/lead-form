      What's in this build

      • Intro cover slide. Filler copy — four trust points plus a format/time/required strip. The intro is not a numbered step, so the flow still reads 01–05.
      • Credit disclosure on step 4. States plainly that no soft or hard check is run, and that a screenshot from a platform the applicant already uses may be requested: Equifax, Experian, TransUnion, Credit Karma, myFICO, Capital One CreditWise.
      • Telegram handle requires 5–32 characters. Telegram's own API enforces this floor, so a shorter handle is rejected inline rather than accepted and lost.
      • Email and phone are hard-required. Format-checked, with persistent inline errors.
      • One action per step. Choosing WhatsApp retargets the submit button to “Submit & open WhatsApp” — the form submits, then the chat opens with your message pre-filled. There is deliberately no second competing button before submit.
      • Satoshi type stack with JetBrains Mono for figures. Use the Type switcher to compare.
      • Field names match the current payload exactly, so porting into Apply.tsx stays mechanical.
